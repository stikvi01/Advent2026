# Advent Calendar – A Personal Math & Illustration Project

## Overview

This project is a digital advent calendar I created as a personal gift for my mom. This is the second version and will be updated. 

Each day presents a small math challenge that must be solved to unlock a hidden illustration.

Behind every “door” is a custom drawing connected to our family—making the experience both playful and meaningful.

## Concept

The idea combines problem-solving with storytelling:

* Each day = one math puzzle
* Solving the puzzle unlocks a unique illustration
* Every illustration reflects shared memories, inside jokes, or family moments


## Features

* 24 interactive “doors,” one for each day leading up to Christmas
* Math-based puzzles of varying difficulty
* Unlock mechanic that rewards correct answers
* Hand-made illustrations tied to family life
* Simple, playful interface focused on exploration

## Design Approach

The project focuses on:

* **Playfulness** – Making math feel fun and approachable
* **Personal storytelling** – Using visuals to reflect meaningful memories
* **Interaction design** – Creating a small sense of anticipation and reward each day

## Purpose

This was a free-time project driven by:

* A desire to create something personal and thoughtful
* Exploring how interaction can enhance emotional experiences
* Experimenting with combining logic (math) and creativity (illustration)
